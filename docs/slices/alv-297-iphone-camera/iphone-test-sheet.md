# iPhone check-in: test sheet (ALV-297)

**Test first on the iPhone with iOS 18.7.1.** That is the phone we have today.

**What we want to learn:** does check-in work on a real iPhone when the photo is taken with Apple's own camera screen? Nobody has tried this on a phone yet. Your results decide if it goes further.

**Use a test login on `dev` only.** Do not use real employee data. Ask Surbhi for the address and a test employee ID.

**If something goes wrong, send a screenshot** with the test number, your iPhone model and its iOS version (Settings > General > About).

## Before you start

1. Open the check-in address in **Safari**. Not Chrome, and not a link inside WhatsApp or Gmail.
2. Set up the phone with the test employee ID. Ask HR to approve it.
3. In Safari, press Share (the box with an arrow), then **Add to Home Screen**, then **Add**.
4. Open the app from the Home Screen. Do all the tests from there, unless a test says Safari.
5. The Home Screen app may ask you to set up again. Tell us if it does, and whether it makes a second "waiting" phone.

You need to be near the test workplace, or use a test login that can check in anywhere.
